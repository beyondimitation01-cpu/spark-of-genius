# Streak — project memory

Habit tracker app ("Streak"), English UI, vintage brown theme with dark/light switch.

## Features
- Habits with streaks, categories (Health, Productivity, Wellbeing), category filters
- Quick picks (22 presets) with category tabs and search
- Daily reminder + per-habit reminder times (browser notifications)
- Statistics panel with charts; Settings with dark mode switch
- Shared top nav with logo; favicon from logo
